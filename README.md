## 工作原理

本仓库使用 Claude Code 作为交互式近世代数考试导师，具有以下功能：
- 采用**苏格拉底方法**教学（首先询问你已经知道的内容）
- 提供简洁（约200字）且数学严谨的解释
- 通过后续问题验证你的理解程度
- 根据你的回答调整教学风格
- **跟踪每个学习会话，个性化你的学习体验**
- **在提供答案前始终使用权威来源验证定理、定义和证明**

## 使用方法

### 日常学习会话

1. 在此仓库中打开 Claude Code
2. 自然地询问近世代数相关问题 - 就像与导师交谈一样
3. 回答 Claude 提出的理解检查问题
4. 每次会话后，Claude 会自动记录：
   - 你学习了什么
   - 你在哪些方面遇到困难
   - 你掌握了什么
   - 下一步需要复习什么

### 复习会话

当你想要复习时，只需询问 Claude：
- "让我们复习一下我遇到困难的主题"
- "今天我应该重点关注什么？"
- "针对我的薄弱环节测试我"
- "显示我的进度"

Claude 会读取你的会话历史，并根据你过去的表现创建个性化的复习内容。

### 跟踪你的进度

查看你的综合学习跟踪器 `/progress/algebra-study-tracker.md`，了解：
- 整体考试准备百分比
- 哪些领域已完成（群、环、域等）
- 剩余的知识差距
- 优先的考试准备学习计划

## 学习理念

**近世代数的引导式学习方法**：
- 对话式、无评判的学习环境
- 基于你已有的数学知识
- 在继续前进前检查理解程度
- 适应你的学习风格
- 注重深层次的概念理解，而非死记硬背
- 强调严谨的证明技巧和逻辑推理
- 将抽象概念与具体实例联系起来

## 主要特性

**个性化学习**：
- 记录学习会话，包含详细的数学笔记
- 苏格拉底教学方法（基于你已有的知识）
- 根据你的数学背景进行适应性解释
- 针对你的薄弱环节定制练习题

**全面跟踪**：
- 每个会话自动记录数学细节
- 按代数结构识别和跟踪知识差距
- 已掌握主题附带置信度和日期
- 根据考试主题权重衡量进度

**基于证据的数学方法**：
- 所有定理、定义和证明都经过权威来源验证
- 不对数学概念进行猜测 - 要求严谨验证
- 为复杂的证明和定义提供引用
- 注重理解代数结构中的"为什么"，而不仅仅是"是什么"

## 如何使用此仓库进行你自己的近世代数考试准备

想要使用这个 AI 驱动的学习系统来准备你自己的近世代数考试吗？很简单：

1. **克隆此仓库**：
   ```bash
   git clone https://github.com/FireWoowoooo/CFP-Study.git
   cd CFP-Study
   ```

2. **切换到代数分支**（或创建你自己的分支）：
   ```bash
   git checkout Abstract-Algebra-teacher
   ```

3. **清除现有学习历史**（如果需要重新开始）：
   ```bash
   rm -rf progress/ sessions/
   ```

4. **运行 Claude Code**：
   ```bash
   claude-code
   ```

5. **就是这样！** 开始询问近世代数问题，Claude 将会：
   - 使用苏格拉底方法进行数学严谨的教学
   - 自动创建新的 `progress/` 和 `sessions/` 文件夹
   - 以数学精度跟踪你的学习历程
   - 在保持数学准确性的同时适应你的学习风格

`CLAUDE.md` 文件包含了 Claude 应如何辅导你学习近世代数的所有指令。**它在保持交互性的同时维持数学严谨性！**

## 开始使用

只需开始与 Claude Code 对话，并询问你的第一个近世代数问题。Claude 将从那里引导你，同时自动跟踪你的进度。
